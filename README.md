# 🎯 OFFER MODE — Career Countdown & Executive Lock Screen Hub

**OFFER MODE** is a production-quality, multi-track career countdown workstation and lock-screen hub. It turns any laptop or auxiliary monitor into an ambient, high-status focus display with millisecond countdowns, custom audio soundscapes, compensation calculators, and real-time interview simulators.

## 🖥️ Executive Lock Screen Features

- **True Fullscreen Mode**: Supported via HTML5 Fullscreen API (`F` hotkey).
- **Millisecond Precision**: Smooth 50ms tick updates showing Days, Hours, Minutes, Seconds, and Milliseconds.
- **Web Audio Sound Engine**: Zero-asset procedural synthesizer using Web Audio API:
  - Ambient focus drones (Cyber sub-bass, binaural 432Hz focus, filtered rain/pink noise, stealth radar pulse)
  - Mechanical keyboard clicks & countdown tick feedback
  - Arpeggiated success fanfare on milestone completion
- **Zen Mode**: Distraction-free clean view toggled via `Space` or `Z`.
- **Slide to Unlock**: Interactive draggable lock slider or press `Esc` to return to dashboard.
- **Track Quick Switcher**: Press `1`, `2`, `3`, `4`, or `5` to switch tracks directly from the lock screen.

## ⌨️ Global Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `L` | Activate Fullscreen Lock Screen |
| `Space` / `Z` | Toggle Zen Mode on Lock Screen |
| `Esc` | Unlock / Return to Dashboard |
| `F` | Toggle Fullscreen |
| `M` | Mute / Unmute Soundscape |
| `1` - `5` | Jump directly to Track 1–5 |
| `0` | Return to Master Overview Dashboard |
