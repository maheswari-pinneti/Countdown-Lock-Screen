# Git Branching & Commit Conventions

## 1. Semantic Commits
Follows Conventional Commits:
- `feat(life-center): ...`
- `fix(auth): ...`
- `test(habits): ...`
- `docs(architecture): ...`

## 2. Protected Main Branch
Changes are merged to `main` only after passing all 7 test suites, typechecks, and builds.
